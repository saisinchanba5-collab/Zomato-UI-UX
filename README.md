# Zomato UI/UX Design

A UI/UX design project inspired by Zomato, focused on creating a clear, user-friendly food discovery and ordering experience.

## Project Overview

This project explores the interface design of a food delivery platform using Figma. It focuses on visual layout, navigation, and presenting food and restaurant information clearly.

## Features

- Restaurant and food browsing
- Food delivery interface design
- Organized screen layouts and navigation
- User-friendly visual design

Completed — UI/UX design in Figma.
